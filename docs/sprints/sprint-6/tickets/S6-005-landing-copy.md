# S6-005 — Update landing page copy

**Priority**: P2
**Status**: Todo

## What
Remove all "free forever / no paywalls" messaging from landing.html and replace with copy that sets up a freemium model.

## Changes

| Location | Current | Replace with |
|----------|---------|--------------|
| Hero badge | "Free to use — no subscription, ever" | "Free to start — Pro for serious gainers" |
| Hero CTA button | "Get started — it's free" | "Start for free" |
| Highlights card (∞) | "Workouts tracked, no paywalls, no usage limits" | "Workouts logged on the free plan — upgrade for unlimited history" |
| Final CTA subtext | "Free to use. No subscription, no paywalls." | "Start free. Upgrade when you're ready to go deeper." |
| Final CTA button | "Get started — it's free" | "Start for free" |

## Acceptance Criteria
- No instance of "no paywalls", "no subscription ever", or "it's free" remains
- Copy still sounds confident and welcoming, not stingy
